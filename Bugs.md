# Отчёт об ошибках

## Список багов

### 1. Отсутствует sellerId в ответе при создании объявления
- **Тест**: `test_create_item_success`
- **Ошибка**: `KeyError: 'sellerId'`
- **Описание**: После успешного создания объявления API не возвращает поле `sellerId` в ответе, хотя тест ожидает его наличие.
- **Ожидаемое поведение**: Ответ должен содержать поле `sellerId` с корректным значением.
- **Серьёзность**: High

### 2. Нет валидации обязательного поля name
- **Тест**: `test_create_item_without_name`
- **Ошибка**: `assert 200 == 400`
- **Описание**: API принимает запрос на создание объявления без обязательного поля `name` и возвращает статус 200 вместо ожидаемого 400.
- **Ожидаемое поведение**: При отсутствии обязательного поля `name` должен возвращаться статус 400 Bad Request.
- **Серьёзность**: High

### 3. Отсутствует id в ответе при создании объявления
- **Тест**: `test_get_item_by_id`
- **Ошибка**: `KeyError: 'id'`
- **Описание**: После создания объявления API не возвращает поле `id`, что делает невозможным последующие операции с этим объявлением.
- **Ожидаемое поведение**: Ответ при создании объявления должен содержать поле `id`.
- **Серьёзность**: Critical

### 4. Неправильный статус-код для несуществующего объявления
- **Тест**: `test_get_item_not_found`
- **Ошибка**: `assert 400 == 404`
- **Описание**: При запросе несуществующего объявления возвращается статус 400 вместо ожидаемого 404.
- **Ожидаемое поведение**: Для несуществующего ресурса должен возвращаться статус 404 Not Found.
- **Серьёзность**: Medium

### 5. Возвращаются объявления несуществующего продавца
- **Тест**: `test_get_items_unknown_seller`
- **Ошибка**: `AssertionError: assert [{'createdAt': ...}] == []`
- **Описание**: Запрос объявлений для несуществующего sellerId возвращает список объявлений вместо пустого массива.
- **Ожидаемое поведение**: Для несуществующего sellerId должен возвращаться пустой список.
- **Серьёзность**: High

### 6. Невозможно получить статистику из-за отсутствия id
- **Тест**: `test_get_statistic_by_id`
- **Ошибка**: `KeyError: 'id'`
- **Описание**: Тест не может получить статистику объявления, так как при создании не возвращается id (зависит от бага #3).
- **Ожидаемое поведение**: Должен возвращаться id при создании объявления.
- **Серьёзность**: High

### 7. Невозможно удалить объявление из-за отсутствия id
- **Тест**: `test_delete_item`
- **Ошибка**: `KeyError: 'id'`
- **Описание**: Тест не может удалить объявление, так как при создании не возвращается id (зависит от бага #3).
- **Ожидаемое поведение**: Должен возвращаться id при создании объявления.
- **Серьёзность**: High

### 8. Неправильный статус-код при удалении несуществующего объявления
- **Тест**: `test_delete_nonexistent_item`
- **Ошибка**: `assert 400 == 404`
- **Описание**: При попытке удаления несуществующего объявления возвращается статус 400 вместо ожидаемого 404.
- **Ожидаемое поведение**: Для несуществующего ресурса должен возвращаться статус 404 Not Found.
- **Серьёзность**: Medium

## Заключение
Все обнаруженные баги связаны с некорректной работой API:
- Отсутствие обязательных полей в ответах
- Неправильные HTTP статус-коды
- Проблемы с валидацией входных данных
- Некорректная фильтрация данных
