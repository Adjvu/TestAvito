# ТЕСТ КЕЙСЫ

## API v1

---

### 1. POST /api/1/item — Создать объявление

| ID | Название | Описание | Ожидаемый результат |
|----|----------|----------|---------------------|
| TC01 | Успешное создание объявления | Переданы все обязательные поля (валидные значения) | 200 OK, в ответе — sellerId, name и другие переданные данные |
| TC02 | Создание без обязательного поля `name` | Пропущено поле `name` | 400 Bad Request |
| TC03 | Создание с невалидным `price` | Указано строковое значение вместо числа | 400 Bad Request |
| TC04 | Дублирование `sellerID` с разными name/price | Тест на возможность создания нескольких объявлений с одинаковым sellerID | 200 OK для всех объявлений |

---

### 2. GET /api/1/item/:id — Получить объявление по ID

| ID | Название | Описание | Ожидаемый результат |
|----|----------|----------|---------------------|
| TC05 | Получить существующее объявление | Передан корректный ID | 200 OK, верные данные |
| TC06 | Получить с несуществующим ID | Нет такого объявления | 404 Not Found |
| TC07 | Получить с некорректным ID | Передан некорректный ID (например, строка) | 400 Bad Request |

---

### 3. GET /api/1/{sellerID}/item — Получить все объявления пользователя

| ID | Название | Описание | Ожидаемый результат |
|----|----------|----------|---------------------|
| TC08 | Получить все объявления по существующему sellerID | Продавец имеет объявления | 200 OK, возвращён список объектов |
| TC09 | Получить по несуществующему sellerID | Продавец не существует | 200 OK, пустой массив |
| TC10 | Получить с невалидным sellerID | Продавец с невалидным ID (например, строка) | 400 Bad Request |

---

### 4. GET /api/1/statistic/:id — Статистика по объявлению

| ID | Название | Описание | Ожидаемый результат |
|----|----------|----------|---------------------|
| TC11 | Получить статистику по существующему объявлению | Передан корректный ID | 200 OK, возвращена статистика |
| TC12 | Получить статистику по несуществующему объявлению | Нет такого объявления | 404 Not Found |

---

## API v2

### 5. GET /api/2/statistic/:id — Получить статистику по объявлению (v2)

|----|----------|----------|---------------------|

### 6. DELETE /api/2/item/:id — Удалить объявление по ID

| ID | Название | Описание | Ожидаемый результат |
|----|----------|----------|---------------------|
| TC14 | Удалить существующее объявление | Передан корректный ID | 200 OK, удаление прошло успешно |
| TC15 | Удалить несуществующее объявление | Объявление с данным ID не найдено | 404 Not Found |
| TC16 | Удалить с некорректным ID | Передан некорректный ID | 400 Bad Request |
